## Bitcoin puzzle transaction ~32 BTC prize to who solves it

Bitcoin puzzle transaction ~32 BTC prize to who solves it

Quoting from the website:

### Description

In 2015, in order to show the hugeness of the private key space (or maybe just for fun), someone created a "puzzle" where he chose keys in a certain smaller space and sent increasing amounts to each of those keys like this:

20 ≤ random key < 21 — 0.001 BTC  
21 ≤ random key < 22 — 0.002 BTC  
23 ≤ random key < 23 — 0.003 BTC  
...  
2255 ≤ random key < 2256 — 0.256 BTC  
(total 32.896 BTC)  

First #1–67 and #70, #75, #80, #85, #90, #95, #100, #105, #110, #115, #120, #125, #130 private keys have already been cracked.

Original puzzle description from the creator (<https://bitcointalk.org/index.php?topic=1306983.msg18765941#msg18765941>) :

>> "A few words about the puzzle.
>> There is no pattern.
>> It is just consecutive keys from a deterministic wallet (masked with leading 000...0001 to set difficulty).
>> It is simply a crude measuring instrument, of the cracking strength of the community."
>>
>> saatoshi_rising on BitcoinTalk
