This section will list small games coded with the help of AI agents. Each game is intended to render and run directly in the client's browser, without server-side gameplay logic.

The purpose is to show, in a practical and playful way, the power and capabilities of AI-assisted software development: fast prototyping, interactive design, and working browser-based experiences that are easy to open, inspect, and improve.

The games here are small experiments, but each one is also a learning opportunity. Have fun learning and playing.
