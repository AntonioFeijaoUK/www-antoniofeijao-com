# Timeline Priority Order - 15 April 2026

## Purpose

This file turns the `93` keeper records from the first triage pass into a practical migration order.

The goal is not simply chronology. The goal is to sequence the backlog in a way that preserves the quality standard already established in the published timeline:

- start with events that best match the timeline's strongest themes
- prefer events with strong primary or authoritative sourcing
- prefer events with clearer historical implications and cleaner narrative structure
- defer items that need slower interpretation, broader synthesis, or more careful framing
